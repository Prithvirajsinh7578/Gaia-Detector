# AI Content Authenticity Detector

## Description

AI Content Authenticity Detector is a full-stack web application that detects whether text, images, videos, and documents are AI-generated or human-created. The project combines machine learning models with a modern web interface to provide fast and reliable authenticity analysis.

## Installation

### Clone Repository

```bash
git clone https://github.com/USERNAME/AI-Content-Authenticity-Detector.git
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```
